# tia-portfolio

Personal portfolio of **Tia Shirzadi**, full-stack software engineer in Melbourne.

Built with Next.js (App Router), React, TypeScript, Tailwind CSS v4 and `motion`, run with Bun and deployed on Vercel.

```bash
bun install
bun run dev        # http://localhost:3000
bun run lint && bun run typecheck && bun test && bun run build
```

Project rules and the build plan live in [`specs/`](./specs).
